Artworks&Artists is a Data Integration & Quality project which uses the MOMA datasets available in https://www.kaggle.com/datasets/momanyc/museum-collection?select=artworks.csv

The dirty dataset artworks.csv is cleaned by using the artists.csv, we feed it into a ETL pipeline where we perform.
- Data Profiling
- Data Quality Assesment
- Data Cleaning (Transformation/Error Correction/Data Deduplication)
